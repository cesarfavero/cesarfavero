## What I Build

> **iGaming Platforms** — Sports betting & online casino systems. Multi-tenant whitelabel architecture with CQRS + Event Sourcing (.NET 8). Game provider integrations (CPGames, PG Soft). Full Brazilian regulatory compliance — Lei 14.790, SIGAP, LOTERPA, KYC/KYB, AML, LGPD, ISO 27001. Responsible Gaming implementation.

> **B2B Real-Time Bingo Game Provider** — Built from scratch with Node.js + TypeScript + WebSocket + Socket.io + React SPA. Delivered as embeddable iframe for third-party operators. Full game engine with real-time state sync, round management, and automated payouts. Comparable to providers like PG Soft and Pragmatic Play.

> **AI & LLM Infrastructure** — Local LLM deployment and inference optimization. RAG architecture with LlamaIndex, Qdrant, and text-to-SQL for natural language analytics dashboards. Video processing pipelines (Whisper + LLaMA + FFmpeg). Automated content generation — text, video, narration, auto-posting. MCP integrations, prompt engineering, and independent research in model efficiency and computational cost reduction.

> **Real-Time Systems** — WebSocket/Socket.io game engines. Event-driven microservices orchestration with bidirectional webhook processing. Payment flow automation (PIX, Asaas). High-reliability patterns — idempotency, circuit breakers, retry/fallback, concurrency control. Strategic caching and latency reduction.

> **Technical Strategy & Business** — Revenue model and pricing strategy structuring. Margin optimization and operational risk assessment. Company structuring (Brazil & USA), fiscal strategy, jurisdiction evaluation. Stack decisions based on risk. SaaS vs own-infrastructure trade-off analysis. Translating complex architecture into financial impact for stakeholders.
