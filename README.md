## What I Build

> **iGaming Platforms** — Multi-tenant whitelabel betting systems with CQRS + Event Sourcing (.NET 8). Full Brazilian regulatory compliance — Lei 14.790, SIGAP, KYC/AML, LGPD.

> **Real-Time Game Engines** — Bingo provider built from scratch with Node.js + WebSocket + Socket.io. Delivered as embeddable iframe for third-party operators.

> **AI Infrastructure** — Local LLM deployment, RAG with text-to-SQL, video processing pipelines (Whisper + LLaMA + FFmpeg). Automated content generation and MCP integrations.

> **Mobile Apps** — Native Android with Kotlin/Compose + Mapbox Navigation SDK. Real-time GPS tracking, group rides, foreground services.
